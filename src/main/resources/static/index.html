🕉️ SANATANA-DHARM API Server

Welcome to SANATANA-DHARM API

This is a Spring Boot application with JWT-based authentication and role-based authorization.

Default Super Admin Credentials:

Username: superadmin

Password: SuperAdmin@123

Email: superadmin@sanatanadharm.com

Available Roles

USER SUPER_USER ADMIN SUPER_ADMIN

Authentication Endpoints

POST /api/auth/signup
Register a new user
POST /api/auth/signin
Login with username/email and password
POST /api/auth/forgot-password
Request password reset
POST /api/auth/reset-password
Reset password with token
GET /api/auth/verify-email?token={token}
Verify email address
POST /api/auth/refresh-token
Refresh JWT token
POST /api/auth/signout
Logout user

Test Endpoints

GET /api/test/all
Public access - no authentication required
GET /api/test/user
Requires USER, SUPER_USER, ADMIN, or SUPER_ADMIN role
GET /api/test/superuser
Requires SUPER_USER, ADMIN, or SUPER_ADMIN role
GET /api/test/admin
Requires ADMIN or SUPER_ADMIN role
GET /api/test/superadmin
Requires SUPER_ADMIN role

User Endpoints

GET /api/user/profile
Get current user profile
GET /api/user/dashboard
Get user dashboard

Admin Endpoints

GET /api/admin/dashboard
Get admin dashboard with statistics
GET /api/admin/users
Get all users with pagination
GET /api/admin/users/{id}
Get user by ID
PUT /api/admin/users/{id}/enable
Enable user account
PUT /api/admin/users/{id}/disable
Disable user account

How to Use

  1. Start by testing the public endpoint: GET /api/test/all
  2. Register a new user: POST /api/auth/signup
  3. Login with credentials: POST /api/auth/signin
  4. Use the JWT token in Authorization header: Bearer {token}
  5. Access protected endpoints based on your role
